# Assets

This directory contains only minimal assets used by the public demo:

- `franka.usd`: Isaac Sim robot scene.
- `realsense.usd`: camera payload referenced by `franka.usd`.
- `banana.usd` and `banana.stl`: demo object assets.
- `005_tomato_soup_can.usd`: sample object asset.

Large Isaac/Omniverse scene collections and texture libraries are intentionally not included. If a future demo needs them, prefer a download script, Git LFS, or a separate asset release with clear license information.
